### 🧰 Herramientas

<p align="center">

#### 01 — TOOL HACKBAR
Colección de herramientas y recursos relacionados con pruebas y experimentación en seguridad informática.
Puede utilizarse como punto de referencia para trabajar con diferentes conceptos, comandos y recursos utilizados durante procesos de aprendizaje y testing.

#### 02 — TOOL VISUAL MAP
Herramienta destinada a la exploración visual de diferentes recursos.
Permite organizar y consultar recursos relacionados con el proyecto de una manera centralizada, facilitando la navegación entre diferentes contenidos.

#### 03 — SIMPLE OSINT TOOL
Conjunto de recursos básicos relacionados con OSINT (Open Source Intelligence).
Está orientado a la consulta y recopilación de información disponible públicamente, siendo útil para aprender conceptos de investigación con fuentes abiertas. (no terminado).

#### 04 — COLLECTION
Recopilación de herramientas y referencias relacionadas con informática y ciberseguridad.
Su objetivo es concentrar diferentes recursos en un mismo lugar para facilitar su consulta y descubrimiento.

#### 05 — LIBRARY T0B1X
Biblioteca de payloads, comandos y referencias utilizados como material de consulta y aprendizaje.
Permite acceder a diferentes ejemplos y recursos relacionados con seguridad informática, testing y experimentación en laboratorios.

#### 06 — T0B1X TERMINAL
Terminal web orientada a la experimentación y aprendizaje.
Incluye funcionalidades relacionadas con:
- Shell virtual.
- Archivos virtuales.
- Utilidades.
- Desarrollo.
- Laboratorios.
- Ejecución de comandos dentro del entorno disponible.
Está pensada principalmente como un entorno de práctica y experimentación. (no terminado).
